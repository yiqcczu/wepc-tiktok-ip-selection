## 原生 IP、家宽 IP、双 ISP，买之前先分清

原生 IP 指 IP 的注册归属地和服务器实际所在国家一致，中间没经过转发或伪装。TikTok 判断账号地域时看的就是这个，机房的普通 IP 发内容经常一开始就没量。

家宽 IP 说的是运营商类型。同一台机器，IP 的注册信息显示为某地宽带用户，而不是数据中心，检测工具里通常写作 ISP 类型或连接类型。

双 ISP 再进一步：一个 IP 带两条运营商属性，住宅特征更明显，风控系统更难把它归到机房那一类。

落到买哪档：

- 只发视频、起号阶段，原生 IP 够用
- 做直播、跑多账号，或者账号已经被限过流，往家宽和双 ISP 走

## 带宽和流量怎么算

1080P 推流码率一般在 3–6Mbps。单路直播间，50–100Mbps 上行远远够用，WePC 多数套餐给到 100–200Mbps，带宽不会是瓶颈。

流量才是容易忽略的一项。TikTok 专线多数给 1–2TB 双向流量，印尼、越南和日本直播线只有 50Mbps 带宽。超出流量不会停机，限速到 5Mbps：发视频基本没感觉，直播会直接卡死。所以直播号优先看流量配额，别只盯着带宽数字。

## 几个容易踩的坑

**英国 10.90 那条不是家宽。** 便宜 4 澳元，ISP 类型不同。发视频、起号没问题，直播间用它会白白多一层风险。

**一台机器一个号。** 同一个 IP 挂多个账号，被关联的概率明显上升。跑矩阵就按账号数买最低配，别把三个号堆在一台 2 核上。

**缺货要看。** 新加坡原生 IDC 那条在列表页显示无库存，热门节点补货不定期，下单前先确认能不能开。

**超流量是限速，不是停机。** 5Mbps 之下直播必挂，发视频能忍。按每月实际用量选流量档，别按峰值估算。

**手机端还有一层。** VPS 解决的是网络 IP，SIM 卡归属地和设备指纹要一起处理，只换 IP 不改设备环境，风控照样能关联上。
